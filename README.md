# CyberGuardian AI

## Overview

CyberGuardian AI is an intelligent cybersecurity monitoring platform that continuously monitors system and network activities, detects suspicious behavior using machine learning, and provides AI-generated threat explanations and remediation recommendations.

## Features

• Real-time CPU, Memory and Disk Monitoring
• Running Process Monitoring
• Network Connection Monitoring
• Open Port Detection
• Machine Learning Threat Detection
• AI-powered Threat Explanation
• Severity Classification
• Threat Alert Generation
• REST APIs using Flask
• Interactive React Dashboard
